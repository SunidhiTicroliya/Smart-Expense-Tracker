## 💼 Smart Expense Tracker (Frontend)

**Smart Expense Tracker** is a corporate-style frontend web application designed to help employees and teams manage expenses, trips, receipts, and approvals through a modern dashboard interface.

### 🚀 Features
- Interactive expense management with real-time UI updates  
- Modules for adding expenses, receipts, trips, and reminders  
- Dashboard view showing pending tasks, approvals, and recent expenses  
- Dark mode enterprise UI with sidebar navigation and card-based layout  
- Scalable frontend structure ready for future backend integration  

### 🛠 Tech Stack
- **HTML5** – Structure and layout  
- **CSS3** – Dark-mode styling, Flexbox-based responsive design  
- **JavaScript (Vanilla)** – Dynamic behavior, event handling, DOM manipulation  

### 🎯 Use Case
Built to simulate a real-world corporate expense management system, suitable for organizations, teams, or internal tools where expense tracking and approvals are required.

### 📌 Project Status
- Frontend completed  
- Backend and data persistence can be integrated in future versions
